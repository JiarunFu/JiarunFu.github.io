# Jiarun Fu — Academic Homepage

A responsive, static academic website for **Jiarun Fu**.

## Website

Deploy with [GitHub Pages](https://docs.github.com/en/pages/quickstart) at **https://jiarunfu.github.io/**.

## Contents

- `index.html` — academic profile, all publications, academic visits, service, contact.
- `styles.css` — fully responsive styling.
- `script.js` — publication year filter and search.
- `assets/portrait.jpg` — profile photograph.
- `assets/favicon.svg` — minimal favicon.
- `.nojekyll` — serves the files as a static website.

No build step, dependencies, or hosting costs are required for a public GitHub Pages site. Open `index.html` locally for a preview.

See `DEPLOY_CN.md` for Chinese publishing instructions.
